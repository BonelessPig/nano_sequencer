How to use calibration mode

The mode sets the table pitch is played from: five points, one per octave, each the DAC value that should give exactly 0, 1, 2, 3 and 4 V. On a real board each is trimmed against a voltmeter. Here the DAC is ideal, so the Pitch CV figure stands in for the meter and nothing needs correcting, but a point can be stored off its mark to see it take effect.

StepDoExpect
1. Enter Click "Enter calibration mode". The sequence stops, the gate stays high and the pitch CV holds still: with the gear on, one steady tone.
2. Pick a point Set step 0's switches to 0, 1, 2, 3 or 4 (switches 1, 2 and 4; a higher value counts as 4). Point n should read n volts.
3. Trim it Turn the tempo pot until the Pitch CV reads the voltage wanted. The middle of the pot (about 512) is the point's nominal value. Its travel covers 64 mV below to 63 mV above, a millivolt for every 8 of the reading. Point 0 cannot go below 0 V.
4. Store it Switch step 15's lowest switch (marked 1) off and on again. The gate drops for a quarter of a second, a gap in the tone, and the debug image logs the point and the value. It is written to the EEPROM there and then.
5. Repeat Do the same for any other points. A point that is not stored keeps the value it had.
6. Leave Change any switch on steps 12 to 15, then click "Power cycle" with "Keep the EEPROM" ticked. The debug image's first log line says Cal = 1, and notes are played from the stored table, on the straight line between the octaves either side.
Back to the ideal table Untick "Keep the EEPROM" and power cycle. The EEPROM is erased and the first log line says Cal = 0.
