Serial log (115200 baud) 

        

        

            What the lines mean
            

                
LineSentMeaning

                
Step n Note = s
                    As a step with a pitch begins
                    n is the step, 0 to 15 (the stage, 0 to 7, on the
                        stage engine). s is the pitch in semitones.

                
Step n Rest
                    As a rest begins
                    The step plays nothing.

                
Transport = t
                    On a change, ahead of the step's own line
                    0 stopped, 1 running on the internal clock, 2 on the
                        external clock.

                
Reset = f Cal = c
                    Once, at start-up
                    f says why the chip started, as a sum: 1 power-on,
                        2 the reset pin, 4 a brown-out, 8 the watchdog. c is
                        1 if a stored calibration table was found.

                
Crash n Place = p Count = c
                    At start-up, if the crash log holds a record
                    The newest record, numbered n, of a watchdog reset.
                        p is where the loop had got to: 1 start-up,
                        2 applying outputs, 3 gathering inputs, 4 in the
                        core, 5 between ticks. c is how many times
                        running, 1 to 255.

                
Cal point p = v
                    When calibration mode stores a point
                    p is the point, 0 to 4, and v the DAC value stored
                        for it, 0 to 4095.

                
… failed, status code = n
                    When something the firmware asked for failed
                    The text names it: initialization, a step note
                        read, an ADC read (the tempo pot), a pitch CV write,
                        a calibration read or write, a crash log read or
                        write.

                
Release image
                    Never
                    It has no log at all.

                
Midi image
                    Never
                    It has no log either: its serial pin carries MIDI,
                        shown under MIDI out.
