MIDI out (D1, 31250 baud)


        

            What MIDI out sends, and what is shown of it
            

                
MessageSentShown

                
Start
                    As the pattern starts: at power-on, after a watchdog
                        reset, and when the run button starts it.
                    A line. The count of clocks begins again.

                
Stop
                    As the run button stops the pattern.
                    A line.

                
Clock
                    24 to a quarter note, which is six to a step. Stopped
                        it carries on at the pot's tempo until an external
                        edge comes. There is none from then on, nor while
                        waiting for an external edge.
                    No line. The count since the last Start, and the
                        tempo over the last quarter note of them, given
                        once there have been seven. With none for a second
                        the tempo is given up.

                
Note On
                    As a gate rises: channel 1, velocity 100. The lowest
                        pitch, 0 V, is note 24 (C1), and a volt is twelve
                        notes.
                    A line, with the note's name and number.

                
Note Off
                    As the gate falls. A note tied to one of another
                        pitch gets its Note Off after the new Note On; a
                        note tied to the same pitch sends nothing.
                    A line.

                
Anything else
                    Never, as the firmware is written.
                    A line giving the byte.

            

            

                The rest of what is shown
                
Times
                    Chip time at which the message's first byte began. A
                        byte takes 320 µs and each waits for the one ahead,
                        so a Note On begins about 0.4 ms after its gate
                        rises, and 0.7 ms behind a Start.

                
Sounding
                    The notes given a Note On and no Note Off yet, as a
                        receiver would have them. A watchdog reset sends no
                        Note Off, so a note it cut short stays here until
                        that note is next played and ended.

                
Transport
                    A Start or a Stop says whether the pattern is
                        running, and is believed over the count of presses
                        of the run button, as the debug image's Transport
                        line is. It does not say which clock.

                
Calibration mode
                    Nothing is sent.

                
Debug and release images
                    Neither sends MIDI: the debug image's serial pin
                        carries its log and the release image's is never
                        switched on.

                
Not emulated
                    Only the bytes are. The MIDI out circuit, and what a
                        receiver makes of the bytes, are not.
